Venus Pro Config generic Linux payload
======================================

This archive mirrors the files installed by the native packages. Install the
runtime packages for your distribution first: Python 3.10 or newer, PyQt6,
and the cython-hidapi module that provides Python's `hid` import.

Copy the archive's usr/ tree into /usr, reload udev rules, then reconnect the
mouse or receiver. Prefer the .deb, .rpm, Arch, Flatpak, or AppImage artifact
when one matches your system.
